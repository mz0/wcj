# Gradle/ Gitlab CI/ JGit playground

Local tasks of interest (substitute `./gradlew` or `../gradlew` or `gradlew.bat` for `gradle` as appropriate):
* `gradle build`, `gradle :lib:depend` etc.
* `gradle hello` (employs JGit)

CI configuration [file .gitlab-ci.yml](.gitlab-ci.yml) effects
can be seen at [origin](https://gitlab.exactpro.com/vivarium/shsha/ci-magic)
